# 개발 로드맵과 체크리스트

최종 갱신: 2026-10-28

이 문서는 프로젝트의 공식 작업 순서와 완료 기준이다. `docs/PROJECT_STATUS.md`는 현재 위치만 요약하고, 실제 작업 선택과 체크 처리는 이 문서를 기준으로 한다.

## 1. 운영 규칙

### 상태 표기

- `[ ]` 미착수
- `[x]` 완료 및 검증됨
- 진행 중 작업은 체크하지 않고 `docs/PROJECT_STATUS.md`에 작업 ID를 기록한다.
- 구현했더라도 완료 기준과 문서 갱신을 충족하지 못하면 완료로 처리하지 않는다.

### 우선순위

- **필수**: 다음 단계 진입 전에 반드시 완료
- **권장**: 해당 마일스톤 품질에 직접 영향
- **선택**: 일정과 인력에 여유가 있을 때 수행

### 전역 완료 정의

모든 작업은 아래 조건을 충족해야 완료로 처리한다.

- [ ] 요구사항과 작업별 완료 기준을 충족한다.
- [ ] 실행 중 새 오류와 경고가 발생하지 않는다.
- [ ] 관련 장면 또는 기능을 직접 실행해 확인한다.
- [ ] 영향받는 기존 기능을 회귀 점검한다.
- [ ] 필요한 문서와 데이터 예시를 갱신한다.
- [ ] 임시 구현과 알려진 제한을 `PROJECT_STATUS.md`에 기록한다.
