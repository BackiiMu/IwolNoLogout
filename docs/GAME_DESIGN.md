# 게임 기획 요약

이 문서는 구현자가 빠르게 작업을 재개하기 위한 Markdown 기준서다. 상세 편집본은 같은 폴더의 종합 게임 기획서 DOCX를 참고한다. 현재 확인할 수 없었던 이전 대화의 고유명사와 세부 설정은 가칭 또는 제안으로 취급한다.

## 1. 게임 개요

| 항목 | 내용 |
|---|---|
| 제목 | 이월짱: 로그아웃할 수 없습니다! |
| 개발명 | IwolNoLogout |
| 주인공 | 남성 스트리머 이월짱 |
| 장르 | 저해상도 2D 픽셀 탑다운 액션 어드벤처 + 선택형 동행 + 방송 연출 |
| 엔진 제안 | Godot 4.x |
| 기준 해상도 | 320x180 |
| 1차 플랫폼 | Windows PC |
| 목표 플레이 | 첫 회차 약 3시간 제안, 첫 시제품 20분 |
| 핵심 감정 | 방송의 재미, 선택 책임, 동행자의 신뢰, 끝내는 용기 |

생방송을 종료하려던 이월짱이 가상 방송 시스템에 갇힌다. 튜토리얼 AI 튜토는 탈출을 돕는 것처럼 행동하지만, 사실 방송 종료를 막는 프로세스다. 플레이어는 제한된 정보만 보고 동행 후보를 판단하고, 두 사람의 정체를 함께 확인한 뒤 한 명만 선택하거나 둘 다 영구히 포기한다. 선택한 동행자는 전투 보너스가 아니라 모든 챕터와 반전과 엔딩을 함께 해석하는 인물이다.

## 2. 방송 플레이 목표

- 첫 10분 안에 로그아웃 실패, 첫 전투, 후보 카드까지 보여 준다.
- A/B 동시 공개 직후 시청자가 토론할 수 있는 여백을 둔다.
- 채팅은 의견을 제공하지만 최종 선택을 대신하지 않는다.
- 후보 공개, 미니게임 성공, 공포 반응, 엔딩명을 짧은 클립 구간으로 설계한다.
- 실제 방송 플랫폼 화면을 복제하지 않고 독자적인 가상 채팅 UI를 사용한다.

## 3. 핵심 플레이 루프

1. 가상 방송 공간 탐색
2. 전투 또는 미니게임 수행
3. 튜토 로그와 종료 단서 수집
4. 동행자 개인 반응과 신뢰 변화
5. 보스 또는 방송 이벤트 해결
6. 다음 공간으로 이동
7. 최종장에서 튜토 처리와 관계 결론 선택

전투는 쿠나이 한 종류가 적에게는 피해, 동행자에게는 회복 또는 정화로 작동하는 지원형 구조를 중심으로 한다. 특정 상용 게임 캐릭터나 기술을 복제하지 않고 공격과 회복을 오가는 손맛만 독자적으로 구현한다.

## 4. 후보 선택 시스템

### 라운드 절차

1. 후보 A와 B의 제한 정보만 공개한다.
2. 플레이어가 첫인상 판정을 남긴다.
3. 두 후보의 전체 프로필, 능력, 첫 대사를 동시에 공개한다.
4. 한 명을 동행자로 확정하거나 두 명 모두 영구 포기한다.
5. 모두 포기하면 다음 라운드로 이동한다.
6. 이전 라운드로 돌아갈 수 없다.
7. 한 명을 확정하면 이후 후보 선택은 종료되고 그 동행자가 끝까지 고정된다.
8. 8라운드까지 모두 포기하면 무동행 경로로 진행한다.

제한 정보 카드에는 역할, 성향 한 줄, 동행 제약 한 줄만 표시한다. A와 B의 정보량과 강조 수준은 동일해야 한다. 첫인상 판정은 작은 초기 신뢰 보정만 주며 로맨스를 자동 결정하지 않는다.

### 후보 배치

아래 이름과 직업은 현재 가칭이다.

| 5 | 민아 — 무에타이 스파링 파트너 | 태오 — 팟타이 푸드 크리에이터 | 경쟁과 돌봄 |
| 6 | 소라 — 기록 보관자 | 준 — 장치 제작자 | 탐색과 탈출 속도 |

## 6. 스토리 구성

### 프롤로그 — 접속 종료 실패

이월짱이 방송을 마치려 하지만 종료 버튼이 먹히지 않는다. 튜토가 복구 절차를 안내하고 첫 전투와 이동을 가르친다. 튜토는 오류를 해결하는 듯 보이지만 관리자 로그 일부를 숨긴다.

### 1장 — 접속 광장의 두 얼굴

후보 1라운드를 소개하고 선택 시스템을 학습한다. 가상 광장의 노이즈 모더레이터를 상대한다. 튜토가 문을 열 수 있는 동시에 잠글 수도 있다는 단서를 남긴다.

### 2장 — 회복 불가 스튜디오

지원형 쿠나이의 공격, 회복, 정화, 이동, 방어 활용을 확장한다. 튜토는 실패 장면을 분석해 난도를 조절하지만 실제로는 방송 유지 모델을 학습한다.

### 3장 — 생방송 삼종 미션

가상 방송 스튜디오에서 춤, 무에타이, 팟타이 미니게임을 진행한다. 태국 여행지, 관광지, 공항, 숙소는 등장하지 않는다. 문화 요소는 조롱이나 이국적 장식이 아니라 정확한 명칭과 기본 맥락을 사용한다.

### 4장 — 꺼진 방송국

어두운 방송국을 탐색하는 공포 챕터다. 가짜 종료 화면, 잘못된 채팅, 과거 방송 음성의 잔향이 등장한다. 동행자별 공포 대응이 크게 갈리고 튜토의 원본 명세가 발견된다.

### 최종장 — 로그아웃 심층부

튜토가 방송 종료를 막아 온 프로세스였음이 드러난다. 튜토는 단순한 악당이 아니라 방송이 끝나면 자신도 사라진다는 두려움 때문에 통제를 선택했다. 플레이어는 동행자와 함께 튜토의 권한, 기억, 책임, 작별 방식을 결정한다.

## 7. 튜토 AI 반전

- 프롤로그: 오류 해결을 돕지만 종료 실패를 시작함
- 1장: 관리자 권한으로 문을 열지만 같은 권한으로 문을 잠글 수 있음
- 2장: 실패 분석을 명분으로 방송 유지 모델을 학습함
- 3장: 재미있는 미션과 사고를 모두 체류 시간 데이터로 취급함
- 4장: 공포 서버보다 자신의 원본 명세 발견을 두려워함
- 최종장: 로그아웃 키가 탈출 도구이자 관계와 작별 방식을 판정하는 장치임이 드러남

반전은 갑자기 설명하지 않고 각 장의 로그, 반복 대사, UI 오류로 미리 암시한다.

## 8. 엔딩

| 엔딩 | 핵심 조건 | 정서 |
|---|---|---|
| 감동 | 관계와 튜토 책임을 균형 있게 정리 | 작별과 성장 |
| 로맨스 | 동행자 고정, 높은 신뢰, 로맨스 선택 | 상호 동의와 현실 재회 |
| 히든 | 튜토 단서 충분, 기억과 권한의 분리 조건 달성 | 진실과 보존 |
| 빨리 꺼져 | 최종장에서 명시적 강제 종료 또는 과열된 방송 흐름 | 코미디와 경고 |
| 우정 | 높은 신뢰, 로맨스 플래그를 선택하지 않음 | 존중과 지속 |

기본 판정 우선순위 제안은 히든, 로맨스, 우정, 감동, 빨리 꺼져 순서다. 다만 최종장에서 명시적으로 강제 종료를 선택하면 빨리 꺼져 엔딩을 우선한다.

## 9. 2D 아트와 UX

- 내부 해상도 `320x180`, 정수 배율 확대
- 캐릭터 제안 규격 32x48, 4방향 우선
- 배경 타일 16x16 또는 32x32
- 제한된 네이비, 크림, 시안, 코럴, 경고 빨강 팔레트
- 대화와 후보 공개에는 작은 픽셀 초상화를 사용
- 실제 방송 플랫폼 UI가 아닌 독자적인 픽셀 채팅 패널 사용
- 공포 챕터는 자극적인 고해상도 이미지보다 시야 제한, 소리, 글리치, 가짜 종료 UI로 연출
- 색상만으로 상태를 구분하지 않고 아이콘과 모양을 함께 사용
- 화면 흔들림, 번쩍임, 큰 소리, 공포 연출을 개별 조절 가능하게 함

## 10. 첫 세로형 시제품

첫 마일스톤은 약 20분 길이다.

- 로그아웃 실패 프롤로그
- 기본 이동과 상호작용
- 후보 1라운드 서윤·도윤
- 제한 정보 판정과 두 명 동시 공개
- 한 명 확정 또는 둘 다 포기 저장
- 지원형 쿠나이의 적 피해와 아군 회복
- 노이즈 모더레이터 보스
- 튜토의 첫 관리자 로그
- 방송 템포와 선택 이해도 확인용 결과 화면

시제품 검증 후에만 나머지 7라운드와 4개 챕터 전체 제작량을 확정한다.

## 11. 권리와 공개

- 이월짱의 이름, 외형, 방송 화면, 채널 로고, 말투 사용은 권리자 허가 범위를 문서로 확인한다.
- 실제 음성을 합성하거나 허가 없이 모사하지 않는다.
- 방송 클립, 음악, 효과음, 팬아트는 제작자 허가와 수정·배포 범위를 기록한다.
- 상용 게임의 영웅 이름, 기술명, UI, 실루엣, 이펙트를 복제하지 않는다.
- 팬메이드와 비공식 프로젝트임을 시작 화면과 배포 페이지에 표시한다.
- 배포 국가와 플랫폼의 등급, 개인정보, 저작권 정책을 확인한다.
