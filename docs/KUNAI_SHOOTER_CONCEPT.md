# 세로 스크롤 쿠나이 전투 제안

최종 갱신: 2026-11-11

상태: **제안 — 첫 스테이지 시제품 검증 후 확정**

## 1. 한 줄 콘셉트

탐색과 대화에서는 기존 탑다운 캐릭터 조작을 유지하고, 전투 구간에 들어가면 이월짱이 가상 방송 공간을 위로 돌파하는 **고전 아케이드풍 세로 스크롤 쿠나이 슈팅 스테이지**로 전환한다.

비행기나 실제 전쟁 배경은 사용하지 않는다. 특정 상용 게임을 복제하지 않고 빠른 세로 진행, 읽기 쉬운 적 편대, 짧고 강한 보스전이라는 장르 감각만 참고한다.

## 2. 채택 목적

- 현재 4방향 이동 기반을 활용하면서 전투의 방향성을 명확하게 만든다.
- 방송에서 짧게 봐도 공격, 회피, 위기, 보스 진입을 이해하기 쉽게 한다.
- 챕터마다 서로 다른 적 패턴과 연출을 넣되 공통 전투 시스템을 재사용한다.
- 쿠나이의 공격·회복 이중 기능을 일반 탄막 슈팅과 다른 핵심 차별점으로 만든다.

## 3. 전체 게임과의 결합

권장 진행 구조는 아래와 같다.

`탐색 → 대화·후보 반응 → 세로 스크롤 전투 → 보스 → 결과와 동행자 반응 → 다음 구간`

- 탐색과 선택은 이야기의 깊이와 관계 변화를 담당한다.
- 슈팅 스테이지는 챕터의 위기와 행동을 담당한다.
- 두 장르를 한 화면에서 동시에 처리하지 않고 명확한 진입·종료 연출로 구분한다.
- 첫 후보 선택 직후 첫 스테이지를 배치해 선택한 동행자의 전투 성격을 바로 체감하게 한다.

## 4. 기본 조작 제안

| 입력 | 기능 | 비고 |
|---|---|---|
| 방향 입력 | 화면 안에서 4방향 이동 | 기존 이동 감각 재사용 |
| 공격 | 전방 쿠나이 연사 | 적에게 피해 |
| 지원 | 동행자 방향으로 회복·정화 쿠나이 | 같은 쿠나이를 대상에 따라 다르게 사용 |
| 집중 | 이동 속도를 낮추고 정밀 회피 | 피격 판정 표시 여부는 시제품에서 검증 |
| 동행자 기술 | 게이지를 소비하는 보조 능력 | 후보별 데이터로 교체 가능 |

첫 시제품에서는 공격과 지원 버튼을 분리한다. 자동 연사 여부, 집중 이동, 피격 판정 표시는 실제 손맛 검수 뒤 확정한다.

## 5. 전투 핵심 규칙

### 공격과 회복

- 공격 쿠나이는 적과 적 투사체에 반응한다.
- 지원 쿠나이는 동행자에게 회복 또는 상태 정화를 제공한다.
- 공격과 지원은 색상만이 아니라 모양, 궤적, 효과음으로 구분한다.
- 동행자를 무한 회복하지 못하도록 지원 잔량이나 짧은 재사용 대기시간을 둔다.

### 동행자

- 동행자는 플레이어 주변의 안전한 위치를 따라간다.
- 후보별 차이는 이동 AI 전체를 새로 만드는 대신 고유 기술과 반응 대사로 표현한다.
- 동행자 체력이 낮아지면 공격만 계속할지 보호에 집중할지 선택하게 한다.
- 동행자가 쓰러져도 즉시 게임오버로 만들기보다 결과와 신뢰에 영향을 주는 방식을 우선 검토한다.

### 실패와 재시작

- 고전식 잔기보다 체력과 체크포인트를 사용한다.
- 스테이지 중간 재시작 시 선택 결과와 이야기 진행은 되돌리지 않는다.
- 보스 재도전은 짧게 유지하고 대사를 반복해서 오래 보지 않도록 한다.

## 6. 챕터별 스테이지 구상

| 구간 | 전투 주제 | 주요 기믹 | 보스 또는 결말 |
|---|---|---|---|
| 프롤로그 이후 | 조작 학습 | 느린 적 편대, 공격·지원 구분 | 작은 오류 코어 |
| 1장 접속 광장 | 노이즈와 검열 | 채팅 모양 방해물, 편대 진입 | 노이즈 모더레이터 |
| 2장 회복 불가 스튜디오 | 회복 차단 | 지원 봉인탄, 정화 타이밍 | 회복 차단 관리자 |
| 3장 삼종 미션 | 리듬과 전환 | 춤 회피, 무에타이 근접 압박, 팟타이 재료 패턴 | 세 미션 결산전 |
| 4장 꺼진 방송국 | 공포와 오인 | 시야 제한, 가짜 탄, 잘못된 경고 | 방송 잔향 집합체 |
| 최종장 | 권한과 로그아웃 | 튜토 권한 패턴, 기억 데이터 보호 | 튜토 코어 다단계전 |
| 최종보스 등장 | 현실 연결 | 전투 경고와 긴장만 연출 | 대사 후 전투 UI 해제 |

현실의 ‘최종보스’는 공격 대상이 아니다. `FINAL BOSS DETECTED` 경고 뒤 “이제 그만 현실로 돌아가자.”라는 대사와 함께 전투 화면이 해제된다.

## 7. 첫 시제품 범위

첫 검증에서는 전체 챕터를 만들지 않는다.

1. 60~90초 길이의 세로 스크롤 구간
2. 적 편대 3종
3. 공격 쿠나이와 지원 쿠나이
4. 플레이어와 동행자 체력
5. 간단한 동행자 기술 1개
6. 중간 경고 연출
7. 1단계 보스 1종
8. 결과 화면의 피격, 구조, 동행자 보호 기록

서윤과 도윤 중 어느 쪽을 골라도 같은 스테이지를 플레이하되 동행자 기술과 결과 대사만 달라지게 한다.

## 8. 방송용 연출

- 편대 전멸, 위험 회피, 동행자 긴급 회복을 짧은 클립 지점으로 만든다.
- 점수 경쟁보다 `노대미지`, `동행자 보호`, `정화 성공`, `보스 격파 시간`을 보여 준다.
- 채팅은 탄막 위를 가리지 않도록 전투 중 표시량을 줄인다.
- 보스 진입 전 2초 안팎의 경고 카드로 방송 시선을 모은다.
- 실패 직후 비난성 문구보다 재도전과 관계 결과를 명확히 안내한다.

## 9. 범위 제한

- 첫 시제품에서 무기 교체, 다수 기체, 복잡한 강화 트리, 온라인 순위표를 만들지 않는다.
- 모든 후보에게 별도 전투 AI와 별도 스테이지를 만들지 않는다.
- 화면을 가득 채우는 고밀도 탄막보다 저해상도에서 읽을 수 있는 패턴을 우선한다.
- 특정 상용 게임의 적 편대, 보스 패턴, UI, 효과음, 전투기 실루엣을 복제하지 않는다.
- 슈팅 때문에 대화와 선택이 부차적으로 보이지 않도록 스테이지 길이를 제한한다.

## 10. 확정 전 검증 질문

- 이월짱이 화면 전체를 움직이는 방식과 하단 영역 중심 방식 중 무엇이 더 자연스러운가?
- 공격은 버튼 연사와 자동 연사 중 무엇이 방송 플레이에 편한가?
- 지원 쿠나이가 수동 조준이어야 하는가, 동행자를 자동 추적해야 하는가?
- 탄막 밀도가 320x180 화면에서 읽기 쉬운가?
- 한 스테이지가 이야기 흐름을 끊지 않는 적정 시간은 몇 분인가?
- 동행자 보호가 재미있는 판단인지 번거로운 호위 임무처럼 느껴지는가?

## 11. 채택 조건

아래 조건을 첫 시제품에서 확인하면 이 방향을 정식 전투 규칙으로 확정한다.

- 처음 보는 플레이어가 공격과 지원 쿠나이를 구분한다.
- 이동과 회피가 저해상도 화면에서도 답답하지 않다.
- 동행자 보호가 전투를 방해하기보다 의미 있는 선택을 만든다.
- 3~5분 전투 뒤에도 이야기와 후보 관계에 관심이 유지된다.
- 방송 화면에서 적, 탄, 플레이어, 동행자, 채팅이 서로 겹치지 않는다.
