## 다음 작업

전체 순서와 체크리스트는 `docs/ROADMAP.md`를 단일 기준으로 사용한다.

1. 사용자 허가 후 타이틀의 개발용 `UI 검수` 버튼으로 01~43 화면을 연속 확인
2. 수정할 화면 번호와 공통 수정 규칙을 한 번에 기록
3. 승인된 레이아웃부터 실제 Control, 입력, 데이터 로직을 연결
4. 타이틀의 새 게임으로 테스트룸 진입을 확인
5. Godot에서 키보드 이동을 5분간 검수
6. 실제 게임패드로 메뉴, 이동, 상호작용을 검수
7. `G2 이동 승인`의 남은 항목을 완료 처리

현재 단계의 완료 조건은 `ROADMAP.md`의 `G2 이동 승인`을 모두 통과하는 것이다.

## 검증 방법

```bash
/Applications/Godot.app/Contents/MacOS/Godot --headless --path game --script tests/smoke_test.gd
/Applications/Godot.app/Contents/MacOS/Godot --headless --path game --script tests/player_movement_test.gd
/Applications/Godot.app/Contents/MacOS/Godot --headless --path game --quit-after 3
```

2026-10-28 기준 Godot 4.7.2에서 기존 스모크 테스트와 부팅 검증을 통과했다. 2026-10-29에 작성한 타이틀 화면, 02~43 레이아웃 장면, UI 검수 갤러리는 사용자 실행 제한에 따라 아직 실행하지 않았다. 제한된 실행 환경에서 macOS 인증서 경로 경고가 표시될 수 있으나 프로젝트 오류는 아니다.
