## 다음 작업

전체 순서와 체크리스트는 `docs/ROADMAP.md`를 단일 기준으로 사용한다.

1. 사용자 허가 후 새 게임으로 프롤로그와 라운드 1 전체 흐름 확인
2. 서윤 확정, 도윤 확정, 둘 다 포기의 저장·재개를 각각 검수
3. 글자 잘림과 버튼 포커스를 수정하고 `G4 선택 승인` 판정
4. 프롤로그·선택 연출을 승인한 뒤 첫 쿠나이 슈팅 스테이지 상세 기획
5. 기존 `G2 이동 승인`의 게임패드와 5분 이동 검수 완료

현재 집중 범위의 완료 조건은 프롤로그와 라운드 1을 세 경로로 검수하고 `ROADMAP.md`의 `G4 선택 승인`을 통과하는 것이다. 기존 `G2 이동 승인`의 수동 항목은 별도로 남아 있다.

전투 방향은 `docs/KUNAI_SHOOTER_CONCEPT.md`의 제안 상태다. 프롤로그·선택 검수 후 60~90초 첫 스테이지 시제품으로 공격·지원 구분, 저해상도 가독성, 동행자 보호의 재미를 확인한 뒤 확정한다.

## 검증 방법

```bash
/Applications/Godot.app/Contents/MacOS/Godot --headless --path game --script tests/smoke_test.gd
/Applications/Godot.app/Contents/MacOS/Godot --headless --path game --script tests/player_movement_test.gd
/Applications/Godot.app/Contents/MacOS/Godot --headless --path game --quit-after 3
```

2026-10-28 기준 Godot 4.7.2에서 기존 스모크 테스트와 부팅 검증을 통과했다. 2026-11-02에 작성한 프롤로그, 라운드 1 선택, 저장·이어하기는 사용자 실행 제한에 따라 아직 실행하지 않았다. 제한된 실행 환경에서 macOS 인증서 경로 경고가 표시될 수 있으나 프로젝트 오류는 아니다.

## 아직 확정이 필요한 사항

- 이월짱의 실제 게임 내 외형과 의상
- 이름, 이미지, 방송 소재 사용 허가 범위
- 현실 애인의 별명 ‘최종보스’, 등장 대사, 관계 설정, 외형, 음성 사용 허가 범위
- 이전 대화에서 별도로 확정된 후보 이름이 현재 가칭과 다른지
- 연애 대상의 성별 범위와 표현 강도
- 16명 후보 로맨스를 유지할지, 현실의 ‘최종보스’와 관계를 재확인하는 엔딩으로 재정의할지
- 공포 강도와 목표 이용 등급
- 무료 공개, 한정 공개, 방송 전용 중 배포 방식
- 음성 녹음과 성우 사용 범위
