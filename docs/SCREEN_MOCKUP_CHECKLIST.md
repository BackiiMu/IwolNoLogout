# 화면 시안 제작 체크리스트

최종 갱신: 2026-11-02

이 문서는 게임에 필요한 화면을 누락 없이 하나씩 설계하기 위한 기준표다. 화면 번호는 파일명과 작업 순서를 함께 결정한다. 현재 승인 검토 기준은 순백·하늘색 테마 v2이며, 기존 어두운 평면 시안과 크림 테마 v1은 비교 자료로 보존한다.

- `[IMG]`: 분위기, 배경, 연출 확인을 위한 이미지 시안 제작
- `[UI]`: 정확한 글자와 조작 흐름을 우선하는 UI 와이어프레임 제작

## 제작 규칙

- 모든 화면은 최종적으로 `320x180` 내부 해상도에서 읽혀야 한다.
- 실제 방송 플랫폼 로고와 UI를 복제하지 않는다.
- 맑은 흰색 배경, 하늘색 보조 면, 순백 패널, 짙은 남청색 글자, 선명한 청록 행동색과 코럴 경고색을 공통 팔레트로 사용한다.
- 베이지와 탁한 회색은 기본 화면에 사용하지 않는다.
- 어두운 네이비 화면은 공포, 접속 끊김, 가짜 종료, 최종 경고처럼 서사상 필요한 장면에만 제한한다.
- 색상 외에 아이콘, 외곽선, 형태로 상태를 함께 구분한다.
- 시안의 문구는 구현할 때 대화·UI 데이터로 분리하고 Godot Control 노드로 다시 작성한다.
- 시안 승인 후에만 다음 번호로 넘어가며, 수정본은 같은 번호의 `v2`, `v3`로 관리한다.
- AI 생성 시안은 분위기 참고 자료로만 보관하고 최종 화면 기준으로 사용하지 않는다.
