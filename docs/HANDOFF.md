# 작업 인수인계와 이력

최종 갱신: 2026-11-02

이 문서는 다른 컴퓨터나 새 작업 세션에서 저장소를 받은 뒤 바로 작업을 이어가기 위한 첫 진입점이다. 세부 현황은 `PROJECT_STATUS.md`, 전체 체크리스트는 `ROADMAP.md`, 확정 변경은 `DECISIONS.md`를 기준으로 한다.

## 1. 현재 한 줄 상태

Godot 이동 테스트룸과 밝은 UI 기반 위에 **로그아웃 실패 프롤로그 12장면과 첫 후보 라운드의 영구 선택·포기·자동 저장 흐름을 구현했으며, 실제 게임 실행 검수는 사용자 요청에 따라 보류 중**이다.

## 3. 2026-11-02 작업 이력

### 최종장 설정

- 시스템이 `FINAL BOSS DETECTED`를 표시한 뒤 이월짱의 현실 애인이 등장하는 반전을 확정했다.
- 현실 애인의 별명도 ‘최종보스’이며 첫 대사는 “이제 그만 현실로 돌아가자.”이다.
- 이 인물은 전투 대상이 아니라 현실 연결을 붙잡아 주는 사람이다.
- 외형과 실제 음성은 당사자 허가 전까지 사용하지 않고 실루엣과 텍스트로만 연출한다.
- 기존 후보 로맨스 엔딩을 현실 애인 중심으로 재정의할지는 아직 제안 상태다.

### 제작 전략

- 전체 챕터를 동시에 얕게 만들지 않고 프롤로그부터 한 구간씩 깊이 있게 완성하기로 확정했다.
- 첫 집중 범위는 `방송 종료 실패 → 튜토 등장 → 첫 후보 라운드 → 결과 자동 저장`이다.
- 쿠나이 전투와 첫 슈팅 스테이지는 프롤로그·선택 검수 이후 진행한다.

### 프롤로그

- 방송 종료 직전부터 동행자 인증 게이트까지 12개 진행 비트를 작성했다.
- 밝은 방송 화면, 종료 지연, 오류, 글리치, 튜토 등장, 인증 게이트의 화면 상태를 구성했다.
- 최근 가상 채팅 반응을 함께 표시한다.
- 튜토가 “방송이 계속되는 동안에는 누구도 사라지지 않습니다”라는 첫 의심 단서를 남긴다.

### 후보 선택 라운드 1

- 서윤과 도윤의 후보 데이터를 JSON으로 분리했다. 두 이름과 세부 직업은 아직 가칭이다.
- 제한 정보 단계에서 A, B, 판단 보류 중 첫인상을 기록한다.
- 이름, 강점, 제약, 첫 대사를 두 후보에게 동일한 형식으로 동시에 공개한다.
- 한 명을 확정하면 이후 후보 선택 전체를 잠근다.
- 둘 다 포기하면 두 후보를 영구 포기 목록에 기록하고 라운드 번호를 2로 올린다.
- 확정과 포기 모두 재확인 뒤 저장 성공 시에만 결과를 표시한다.

### 저장과 타이틀

- `GameState` 자동 로딩 서비스를 추가했다.
- 프롤로그 대사 위치, 첫인상, 공개 단계, 최종 선택 결과를 자동 저장한다.
- 임시 파일과 이전 저장 백업을 사용해 저장 중 손상 가능성을 줄였다.
- 타이틀의 `새 게임`은 프롤로그로 진입한다.
- 저장이 있으면 `이어하기`가 활성화된다.
- 기존 진행이 있을 때 새 게임을 누르면 덮어쓰기 확인창을 표시한다.

## 5. 검증 상태

### 완료

- 두 JSON 파일의 문법 검사
- 변경 파일의 공백과 Git diff 검사
- 필수 파일과 `res://` 참조 경로 확인
- 스모크 테스트에 프롤로그 장면과 JSON 데이터 존재 검사 추가

### 실행하지 않음

사용자가 명시적으로 허락할 때까지 게임 실행을 제한했기 때문에 2026-11-02 구현분은 Godot에서 실행하지 않았다. 자동 테스트도 Godot 실행에 해당하므로 이번 작업에서는 돌리지 않았다.

## 6. 다음 작업자가 바로 할 일

사용자의 실행 허가를 먼저 확인한 뒤 아래 순서로 진행한다.

1. 타이틀에서 새 게임을 선택해 프롤로그 첫 화면 진입 확인
2. 프롤로그 중 타이틀로 나갔다가 이어하기로 같은 위치 복귀 확인
3. 서윤 확정 경로 저장·재개 확인
4. 도윤 확정 경로 저장·재개 확인
5. 둘 다 포기 경로의 영구 잠금 확인
6. 320x180 화면의 한글 잘림, 버튼 포커스, 게임패드 이동 확인
7. 오류를 수정한 뒤 `ROADMAP.md`의 `G4 선택 승인` 판정
8. 승인 후 첫 쿠나이 세로 스크롤 슈팅 스테이지 상세 기획 시작

## 7. 아직 결정하지 않은 사항

- 서윤과 도윤의 이름과 최종 프로필
- 16명 후보 로맨스를 유지할지 현실의 ‘최종보스’와 관계를 재확인하는 엔딩으로 변경할지
- 현실 인물의 이름, 별명, 관계, 외형, 음성 사용 허가 범위
- 공포 강도와 목표 이용 등급
- 무료 공개, 한정 공개, 방송 전용 중 배포 방식
- 1945풍 세로 스크롤 쿠나이 전투를 전체 전투 규칙으로 확정할지 여부

## 8. 작업 시 주의사항

- 게임 실행은 사용자 허가 전까지 하지 않는다.
- 후보 이름과 수치가 가칭이면 문서와 데이터에서 확정으로 표현하지 않는다.
- 선택 잠금 로직을 화면 표시만으로 구현하지 말고 `GameState`를 기준으로 유지한다.
- 실제 인물의 음성을 합성하거나 외형을 허가 없이 제작하지 않는다.
- 특정 상용 슈팅 게임의 적, 탄막, UI, 음향을 식별 가능하게 복제하지 않는다.
- 작업 종료 전 이 문서, `PROJECT_STATUS.md`, `ROADMAP.md`, `DECISIONS.md`를 함께 갱신한다.
