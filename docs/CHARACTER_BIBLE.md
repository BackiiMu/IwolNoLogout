# 캐릭터 디자인 바이블

최종 갱신: 2026-10-29

## 1. 문서 상태

- 대상: 남성 주인공 이월짱
- 상태: 프로필 기반 디자인 방향 승인, 기본 이동 스프라이트 v1 제작
- 기준 이미지: 사용자가 제공한 유튜브 프로필 이미지
- 현재 용도: 공통 아트 방향, 프롤로그 화면 시안, 게임 내 기본 이동 자산 기준

## 2. 반드시 유지할 특징

- 짙은 녹색의 짧고 뾰족한 머리
- 분홍색과 크림색으로 구성된 고양이 귀 형태의 머리 장식
- 크고 밝은 회색 눈
- 친근하고 활기찬 남성 인상
- 흰색 랩 스타일 상의와 짙은 색 테두리
- 녹색, 분홍색, 흰색의 즉시 구분되는 조합

위 특징은 작은 게임 화면에서도 이월짱을 알아볼 수 있게 만드는 핵심 식별 요소다. 장식이나 의상을 추가하더라도 이 실루엣과 색상 관계를 가리지 않는다.

## 3. 픽셀 규격

| 항목 | 기준 |
|---|---|
| 게임 캐릭터 | 32x48 픽셀 |
| 이동 방향 | 상하좌우 4방향 |
| 대기 | 방향별 1프레임, 추후 2프레임 확장 검토 |
| 걷기 | 방향별 좌우 발 2프레임, 4단계 순환 |
| 대화 초상화 | 96x96 픽셀 |
| 작은 아이콘 | 32x32 픽셀 |
| 텍스처 필터 | nearest-neighbor |

캐릭터의 머리와 고양이 귀 장식이 전체 높이의 약 40퍼센트를 차지하게 하고, 흰색 상의와 어두운 하의를 분명히 나눈다. 손과 발의 세부 묘사보다 머리 장식과 얼굴 방향을 우선한다.

## 4. 색상 방향

- 머리: 짙은 청록 또는 녹색
- 머리 장식: 코럴 분홍과 크림
- 피부: 밝은 피치
- 상의: 따뜻한 흰색과 크림
- 테두리와 하의: 짙은 네이비 또는 차콜
- 눈: 중성 회색
- 회복·튜토 연출: 시안
- 위험·오류 연출: 코럴 빨강

정확한 팔레트 값은 실제 32x48 스프라이트를 제작하면서 12색에서 16색 안으로 제한한다.

## 5. 표정 세트

프롤로그에서 먼저 제작할 표정은 다음 네 가지다.

1. 밝은 기본 표정
2. 로그아웃 오류를 본 놀란 표정
3. 튜토를 의심하는 걱정 표정
4. 첫 전투에 들어가는 결연한 표정

추가 표정은 챕터별 필요에 따라 제작한다. 초반부터 표정을 과도하게 늘리지 않는다.

## 6. 의상과 동작 규칙

- 기본 흰색 랩 스타일 상의는 유지한다.
- 전투 기능은 의상 변경보다 쿠나이와 손의 시안 빛으로 표현한다.
- 실루엣을 가리는 큰 망토, 가방, 긴 장식은 사용하지 않는다.
- 대기 동작은 가벼운 호흡과 머리카락 움직임으로 제한한다.
- 걷기 동작은 상체 흔들림을 줄이고 발 위치를 분명히 한다.
- 쿠나이 동작은 준비, 투척, 후속, 회수 또는 재생의 네 단계로 구성한다.

## 8. 권리 확인

- 프로필 이미지의 원본 제작자와 사용 권한을 확인한다.
- 프로필 이미지를 게임 파일에 그대로 포함하려면 별도 허가를 받는다.
- 현재 시안은 특징을 픽셀 캐릭터로 재해석한 디자인 초안으로 관리한다.
- 배포 전 이월짱 본인의 이름, 이미지, 연애 표현 사용 범위를 확인한다.
