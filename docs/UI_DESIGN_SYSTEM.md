# UI 디자인 시스템

최종 갱신: 2026-10-29

## 1. 목표

`이월짱: 로그아웃할 수 없습니다!`의 모든 화면을 `320x180` 내부 해상도에서 일관되게 제작한다. 화면은 콘셉트 아트처럼 꾸미지 않고 실제 Godot UI로 옮길 수 있는 평면 구조를 우선한다.

Notion 디자인 분석 문서에서는 간격, 계층, 단일 강조색, 조용한 표면 구성 원칙만 참고한다. Notion의 색상, 외형, 아이콘, 글꼴, 고유 컴포넌트는 복제하지 않는다.

## 2. 금지 규칙

- AI 이미지에서 흔히 나타나는 과도한 네온, 반사광, 블러, 미세 장식을 사용하지 않는다.
- 한 화면에서 여러 색을 동시에 주요 행동색으로 사용하지 않는다.
- 배경과 UI에 의미 없는 글리치를 반복하지 않는다.
- 읽을 수 없는 장식용 문자와 가짜 한글을 사용하지 않는다.
- 실제 방송 플랫폼, Notion, 상용 게임의 UI를 복제하지 않는다.
- 확정되지 않은 후보의 얼굴과 의상을 임의로 디자인하지 않는다.

## 3. 기준 해상도와 그리드

| 항목 | 값 |
|---|---:|
| 내부 해상도 | 320x180 |
| 최소 단위 | 2px |
| 기본 단위 | 4px |
| 주요 간격 | 4px, 8px, 12px, 16px |
| 화면 안전 여백 | 좌우 12px, 상하 8px |
| 패널 내부 여백 | 8px |
| 목록 행 높이 | 20px 또는 24px |
| 최소 선택 영역 | 24x16px |
| 기본 외곽선 | 1px |

좌표와 크기는 가능한 한 짝수로 맞춘다. 같은 단계의 화면은 제목 위치, 뒤로 가기 위치, 선택 강조 위치를 유지한다.

## 4. 공통 팔레트

기본 화면은 순백과 맑은 하늘색을 사용해 깨끗한 방송 화면 느낌을 만든다. 베이지와 탁한 회색은 사용하지 않는다. 공포, 연결 끊김, 가짜 종료, 최종 경고처럼 서사적으로 필요한 화면만 어두운 반전 화면을 사용한다.

| 역할 | 색상 | 용도 |
|---|---|---|
| 배경 0 | `#F7FCFF` | 맑은 흰색 화면 바탕 |
| 배경 1 | `#E8F7FF` | 방과 맵의 하늘색 보조 면 |
| 패널 | `#FFFFFF` | 기본 UI 패널 |
| 패널 강조 | `#DDF6FF` | 선택 행과 정보 구역 |
| 외곽선 | `#14324A` | 캐릭터와 UI 외곽선 |
| 기본 글자 | `#10283B` | 제목과 본문 |
| 보조 글자 | `#557286` | 설명과 비활성 상태 |
| 행동색 | `#00B8D9` | 현재 선택, 확인, 링크 |
| 행동색 눌림 | `#007F9E` | 눌림 상태 |
| 오류색 | `#FF5573` | 오류, 위험, 영구 포기 |
| 회복색 | `#28C98B` | 회복과 안전 상태 |
| 경고색 | `#FFB229` | 주의와 미확정 정보 |

시안은 구조를 담당한다. 코럴은 오류와 위험에만 사용하고, 장식 목적으로 넓게 칠하지 않는다. 흰색 패널과 하늘색 배경을 구분할 수 있도록 외곽선을 항상 유지한다.

## 5. 글자 계층

실제 폰트는 한글 가독성, 라이선스, Godot 렌더링을 확인한 뒤 확정한다. 시안에서는 굵은 고딕 계열을 사용한다.

| 역할 | 기준 크기 | 굵기 | 용도 |
|---|---:|---:|---|
| 로고 | 18~22px | 800 | 타이틀 전용 |
| 화면 제목 | 12px | 700 | 저장, 설정, 후보 공개 |
| 소제목 | 9px | 700 | 슬롯명, 화자명 |
| 본문 | 8px | 500 | 대화와 설명 |
| 보조 | 6px | 500 | 시간, 날짜, 조작 안내 |

- 제목과 본문 사이에는 최소 4px을 둔다.
- 본문 한 줄은 한글 약 24자 이내로 제한한다.
- 그림 위에 글자를 직접 놓지 않고 단색 패널을 사용한다.

## 6. 패널과 버튼

### 기본 패널

- 배경: 패널 색상
- 외곽선: 외곽선 색상 1px
- 모서리: 직각 또는 2px 계단형
- 그림자와 블러: 사용하지 않음

### 선택 행

- 행동색 1px 외곽선
- 왼쪽에 4px 크기의 쿠나이 커서
- 글자색을 기본 글자로 유지
- 선택되지 않은 행은 패널 강조색과 보조 글자를 사용

### 위험 행동

- 기본 선택값으로 두지 않는다.
- 오류색 글자와 경고 아이콘을 함께 사용한다.
- 영구 포기, 삭제, 강제 종료는 확인 화면을 한 번 더 거친다.

## 7. 화면별 구조

- 타이틀: 왼쪽 제목과 메뉴, 오른쪽 게임 세계의 단순 장면
- 저장·불러오기: 왼쪽 슬롯 목록, 오른쪽 선택 슬롯 상세
- 설정: 왼쪽 카테고리, 오른쪽 옵션 목록, 하단 조작 안내
- 기본 플레이: 왼쪽 위 상태, 오른쪽 가상 채팅, 하단 능력
- 후보 선택: 같은 크기의 A/B 카드와 중앙 판정 영역
- 대화: 하단 대화 패널, 좌우 초상화, 화자명 우선
- 엔딩: 넓은 여백, 엔딩명, 인물 한 명 또는 상징 한 개

## 8. 제작 절차

1. `320x180`에서 회색 상자로 구조를 배치한다.
2. 정확한 한국어 문구를 넣는다.
3. 공통 팔레트만 적용한다.
4. 확정된 스프라이트와 아이콘만 추가한다.
5. 2배와 4배 확대 상태에서 픽셀 정렬을 확인한다.
6. 구조 승인을 받은 뒤 Godot Control 노드로 구현한다.

## 9. 완료 기준

- 확대하지 않은 `320x180` 화면에서도 핵심 글자가 읽힌다.
- 현재 선택과 위험 행동이 색상 없이도 구분된다.
- 패널의 간격과 제목 위치가 다른 화면과 일치한다.
- 임의 생성된 얼굴, 가짜 문자, 과한 광원 효과가 없다.
- 실제 게임에서 구현할 수 없는 장식이 없다.
